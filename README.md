# MIG Scheduling Research

This is the GitHub repository for the MIG scheduling research project.

## Project bundle

The complete M1–M13 project bundle is prepared separately and includes:
- MIG simulator, scheduling policies, and score variants
- Experiment scripts, configurations, test suite, and generated results
- Research audits, milestone reports, protocols, and reproducibility notes
- Final presentation files (PPTX, PDF, and DOCX brief)

**Import status:** The project bundle has not yet been uploaded to this repository. The initial repository setup is complete; the full bundle needs to be copied into this repository and pushed.

## Upload the full bundle

Extract `MIG_Scheduling_Research_Repo.zip`, copy its contents into a local clone of this repository, then commit and push the files to `main`.

The ZIP includes its own `.gitignore`. Keep generated Python environments (such as `.venv`) and local caches out of version control.
